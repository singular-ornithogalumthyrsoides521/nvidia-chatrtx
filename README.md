## ⚠️ Troubleshooting Tips

If you face issues, check these common items:

*   **The app refuses to open:** Check your NVIDIA drivers. Old drivers prevent the AI core from starting. Use the GeForce Experience tool to update your drivers.
*   **The chat feels slow:** Close other apps that use your graphics card, such as video games or photo editors. AI needs high memory usage to work well.
*   **Files do not show up:** Ensure your files have text, not just images. If a PDF is a scan of a paper, the software cannot read the handwriting inside it. Use a document that has selectable text.
*   **Memory Errors:** If you see an error saying "Out of Memory," you have too many files indexed. Remove some folders from the data menu to free up space in your graphics card memory.
